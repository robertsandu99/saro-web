First Steps (Local Setup)

1
Python 3.11 ✓ Already installed
You have Python 3.11.0. We will use this version. No action needed.
2
Docker Desktop ✓ Already installed
Docker 29.9.2 and Docker Compose v5.6.1 are ready. Make sure Docker Desktop is running before starting containers.
3
Poetry ✓ Already installed
Poetry 1.7.1 is installed. Used to manage Python dependencies and virtual environments. Run poetry install inside the project after setup.
4
Git ✓ Already installed
Git 2.47.1 is ready. Push your project to GitHub to enable CI/CD and free cloud deployments.
5
Initialize the project structure
Run poetry init inside saro-web/ to create pyproject.toml, then add FastAPI, SQLAlchemy, Alembic, etc. as dependencies.
6
Create docker-compose.yml (local dev)
Define services: api (FastAPI), db (PostgreSQL), nginx. This same file will be reused on the Oracle Cloud server with minimal changes.
7
Create a GitHub repository
Push saro-web to GitHub. This enables GitHub Actions for automated testing and deployment to Oracle Cloud.
8
Register Oracle Cloud free account
Sign up at cloud.oracle.com. Create the ARM Ampere A1 VM (4 OCPUs, 24 GB RAM). This is your free permanent server. Requires a credit card for identity verification — you will NOT be charged.
9
Register Cloudflare (free) + buy domain
Buy a .com domain (~$10-15/yr on Porkbun or Namecheap). Point DNS to Cloudflare (free). Cloudflare gives you DDoS protection, CDN, and SSL with zero config.
10
Deploy to Oracle Cloud
SSH into the VM, install Docker, copy your docker-compose.yml, run docker compose up -d. Same stack as local — instant deploy.

Backend

⚡
FastAPI
Python web framework. Async-first, auto-generates Swagger UI documentation at /docs. Very fast, type-safe via Pydantic.
FreePython installed
🗄️
SQLAlchemy 2.x (async)
ORM (Object-Relational Mapper). Lets you write Python classes instead of raw SQL. Async version works with FastAPI's async model.
FreeRequired
🔌
asyncpg
Async PostgreSQL database driver. Required by SQLAlchemy to talk to PostgreSQL asynchronously.
FreeRequired
📦
Pydantic v2
Data validation and settings management. Validates API request/response schemas and reads config from environment variables.
FreeRequired
🚀
Uvicorn
ASGI web server. Runs the FastAPI application. Included with FastAPI. Command: uvicorn app:app --host 0.0.0.0 --port 8080
FreeRequired
🔄
Alembic
Database migration tool for SQLAlchemy. Tracks and applies schema changes (create tables, add columns) in a versioned, safe way.
FreeRequired
🔑
PyJWT
Creates and validates JWT tokens for user authentication. Users log in, receive a token, and send it with every request.
FreeRequired
📋
Poetry
Python dependency and virtual environment manager. Replaces pip + requirements.txt with a cleaner pyproject.toml.
FreeInstalled v1.7.1

Database

🐘
PostgreSQL 16
Primary relational database. Runs in a Docker container locally and on Oracle Cloud. No cloud subscription needed — self-hosted, free, 200 GB available on the Oracle VM.
Free (self-hosted)Docker container
🖥️
pgAdmin 4
Visual database management UI. Already installed. Connect to your local PostgreSQL container or the remote Oracle Cloud DB to inspect tables and run queries.
FreeAlready installed
☁️
Neon (alternative)
Managed cloud PostgreSQL if you prefer not to self-host. Free tier: 1 GB storage, no expiration, no credit card. Good backup option.
Free tierOptional

Infrastructure

🐳
Docker Compose
Orchestrates all services (API, database, Nginx) with a single docker-compose.yml file. Same file runs locally and on the server. Command: docker compose up -d
FreeInstalled v5.6.1
🔀
Nginx
Reverse proxy server. Sits in front of FastAPI, handles SSL termination (HTTPS), serves static files, and routes traffic. Runs as a Docker container.
FreeRequired

Best permanent free cloud server. ARM VM with 4 OCPUs + 24 GB RAM, 200 GB storage, 10 TB/month outbound bandwidth. Free forever (since 2019, stable). Requires credit card for identity — you are NOT charged.
FREE foreverMain server

Security & HTTPS

🔒
Cloudflare (free tier)
Sits between the internet and your server. Provides DDoS protection, CDN (caches content globally), basic Web Application Firewall, and SSL. Hides your real server IP. Free forever.
FreeStrongly recommended
🏅
Let's Encrypt + Certbot
Free SSL/TLS certificates for HTTPS. Auto-renews every 90 days via Certbot. This is what powers the padlock in the browser URL bar. Free forever.
FreeRequired for HTTPS
🛡️
WireGuard VPN
Self-hosted VPN on the Oracle server. Used for admin access only — SSH is blocked from the internet and only accessible via VPN. End users do NOT need VPN to visit the website.
FreeAdmin access
🚫
Fail2ban
Monitors server logs and auto-bans IP addresses with repeated failed login attempts. Protects against brute force attacks. Runs on the Oracle VM.
FreeRecommended

For the team balancing feature, a Python algorithm (weighted shuffling, constraint satisfaction) is better than AI — faster, deterministic, free, no API calls. No external service needed.
